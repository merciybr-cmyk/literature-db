# 과목 필터 추가 · '구분' → '학교급' 라벨 변경 설계

작성일: 2026-08-13

## 배경 / 목표

검색 페이지 필터에서:

1. 기존 '구분' 필터(중등/고등)의 **라벨을 '학교급'으로 변경**한다. 필드값(`구분`)과 옵션(중등/고등)은 그대로 둔다.
2. 새 **'과목' 필터**를 추가해 `국어`/`문학`을 선택할 수 있게 한다.

중등은 전부 국어, 고등은 국어와 문학으로 나뉜다. 교육과정기별로 교과서상 과목 이름이 조금씩 다르지만(공통국어1, 국어Ⅰ, 문학Ⅱ 등) 필터는 `국어`/`문학` 두 값으로 정규화한다.

## 과목 판정 규칙

데이터에 별도 `과목` 컬럼이 없으므로 **교과서명에서 자동 도출**한다.

- 교과서명에 `"문학"`이 포함되면 → `문학`
- 그 외 → `국어`

근거(현재 데이터 기준):
- 문학: `문학`, `문학Ⅰ`, `문학Ⅱ`
- 국어: `국어`, `국어 1/2/3`, `국어 (상)/(하)`, `국어Ⅰ/Ⅱ`, `국어 상/하`, `공통국어1/2`, `고등 국어 1`, `중학 국어 1-1` 등

새 교육과정이 추가돼도 이 규칙(문학 포함 여부)만 맞으면 자동 처리된다.

## 변경 사항

### 1. `src/utils/parseCSV.js` — 파생 필드
- 헬퍼 `subjectOf(work)` 추가: 교과서명 기반으로 `'문학'` 또는 `'국어'` 반환.
- `withDerivedFields`에 `_subject: subjectOf(work)` 추가.
- `useWorks`가 라이브 CSV(parseCSV)와 로컬 works.json(map(withDerivedFields)) 모두 이 함수를 통과시키므로 검색·통계·비교 등 전 화면에 자동 반영된다. works.json 재생성은 불필요(선택).

### 2. `src/constants.js` — 도메인 상수
- `DIVISIONS = ['중등', '고등']` 유지.
- `SUBJECTS = ['국어', '문학']` 추가.

### 3. `src/utils/filterWorks.js` — 필터 로직
- 시그니처에 `subject = []` 파라미터 추가.
- 조건 추가: `if (subject.length && !subject.includes(work._subject ?? subjectOf(work))) return false`
- 기존 초성 폴백과 동일하게 `??`로 안전 처리(파생 필드 누락 대비).

### 4. `src/components/search/FilterPanel.jsx` — UI
- `division` 필터의 `label`을 `'구분'` → `'학교급'`으로 변경.
- `FILTER_CONFIGS`에 `{ key: 'subject', label: '과목', options: SUBJECTS }`를 학교급 바로 뒤에 추가.
- 필터 순서: 교육과정 · 체제 · 학교급 · 과목 · 장르 · 학년 · 출판사.

### 5. `src/components/search/ActiveFilters.jsx` — 활성 필터 칩
- `FILTER_LABELS`의 `division: '구분'` → `division: '학교급'`으로 변경.
- `FILTER_LABELS`에 `subject: '과목'` 추가.
- 칩 렌더·삭제·전체 초기화는 `FILTER_LABELS` 키를 순회하므로 자동 반영된다.

### 6. `src/utils/exportExcel.js` — 엑셀 내보내기
- `exportToExcel`은 이미 필터된 `works`를 받아 고정 컬럼으로 출력하므로 **과목 필터 자체는 별도 배선 불필요**(필터는 상위에서 적용됨).
- 다만 결과 행에 과목 정보가 드러나도록 `_subject`를 컬럼으로 추가한다: `교육과정` 다음 또는 `구분`(학교급) 옆에 `'과목': w._subject`. 파생 필드 누락 대비 `w._subject ?? subjectOf(w)` 폴백 사용.

### 7. 테스트
- `src/tests/filterWorks.test.js`
  - `subjectOf` / `_subject` 도출 규칙 테스트(문학 포함 → 문학, 그 외 → 국어).
  - 과목 필터 단독 및 다른 필터와 조합 테스트.

## 동작 예시

- 과목 = `문학` 선택 → 중등(전부 국어) 전량 제외, 고등 문학만 표시.
- 과목 = `국어` 선택 → 중등 전체 + 고등 국어.
- 과목 미선택 → 필터 무효(전체 통과), 기존 동작과 동일.

## 비목표 (YAGNI)

- 시트에 `과목` 컬럼을 실제로 추가하지 않는다(자동 도출로 충분).
- 국어/문학 외 세부 과목명(공통국어, 국어Ⅰ 등)을 개별 필터 값으로 노출하지 않는다.
- 통계/비교 페이지에 과목 전용 차트/뷰를 새로 만들지 않는다(파생 필드는 존재하나 UI 신설은 범위 밖).
